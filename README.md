# 🎪 수학 체육올림픽 (초등 5학년 2학기)

**초등학교 5학년 2학기 수학 × 체육 융합 · 모션인식 기반 웹 교육 게임**

태블릿을 책상 위에 놓고 앉은 채로, 손을 움직이거나 태블릿을 터치하거나 PC에서 마우스로 조작하며 즐기는 6종목 미니게임 모음입니다. 별도 설치 없이 웹 브라우저에서 바로 실행됩니다.

`motion-math-olympics`(2학년) · `motion-math-olympics-1st`(1학년) · `motion-math-olympics-3rd`(3학년)와 같은 엔진을 쓰는 **시리즈 4번째 작품**이며, 이번 판부터 **마리오파티 스타일의 파티 보드 구조**가 추가되었습니다.

---

## 📖 소개

5학년 2학기 수학 6개 단원(수의 범위와 어림하기, 분수의 곱셈, 합동과 대칭, 소수의 곱셈, 직육면체, 평균과 가능성)을 **5학년 체육과의 「거리 도전(제자리멀리뛰기·투구)」과 「필드형 경쟁(티볼 타격·베이스런·수비)」** 영역과 묶어 6종목으로 재구성했습니다.

이전 학년판이 "종목 카드 6개 → 60초 → 메달"로 끝났다면, 5학년판은 **주사위를 굴려 보드를 돌고 코인을 모아 별로 바꾸는** 파티 게임 구조를 얹었습니다.

## ✨ 주요 특징

- **🎲 파티 보드**: 12칸 순환 보드(종목 6칸 + 이벤트 6칸)를 주사위로 돌며 종목에 도전. 별 6개를 모으면 🏆 종합 우승
- **📋 자유 선택 탭**: 수업에서 특정 단원만 다룰 때는 카드로 바로 골라 시작 (보드와 병행)
- **🐾 마스코트 6마리**: 종목마다 담당 캐릭터가 룰을 설명하고 표정으로 반응
- **📜 룰카드**: 게임 시작 전 캐릭터가 조작법을 말풍선으로 안내 (7초 후 자동 진행 · 건너뛰기 가능)
- **🏆 시상대 결과**: 코인이 하나씩 세어지며 ⭐별로 환산되는 결과 발표
- **3가지 조작 방식**: 모션인식(카메라로 손 인식) / 터치(태블릿) / 마우스(PC)
- **자동 난이도 조절**: 3연속 정답이면 한 단계 상승, 2연속 실패면 하락 (⭐ 개수로 표시)
- **하이라이트 자동 저장**: 가장 잘한 순간의 사진과 3초 영상을 기기에 저장 (서버 전송 없음)
- **완전 반응형 · 오프라인 친화적**: 손 인식 AI 모델을 자체 서버에 내장해 학교 네트워크에서도 안정적으로 동작

## 🎮 6개 종목

| 종목 | 캐릭터 | 수학 단원 | 체육 연계 | 조작 방식 |
|---|---|---|---|---|
| 1 🦘 어림 멀리뛰기 | 🐰 깡총이 | 수의 범위와 어림하기 | 거리 도전(제자리멀리뛰기) | 손으로 **조준**하고 멈추면 도약 → 조건에 맞는 수의 **착지 매트**에 착지 |
| 2 🥎 분수 캐논 투척 | 🐿️ 도토리 | 분수의 곱셈 | 거리 도전(투구) | 좌우로 움직이는 **힘 게이지**를 계산한 거리에서 멈춰 발사 |
| 3 🪞 대칭 수비 미러 | 🐧 미로 & 라로 | 합동과 대칭 | 필드 수비 | 타구의 **대칭인 자리**를 손으로 막기 (⭐⭐⭐는 **양손**) |
| 4 📡 소수 비거리 레이더 | 🦊 재보 | 소수의 곱셈 | 거리 계측 | 계산한 값의 **눈금에 손을 0.7초 대고** 계측 |
| 5 📦 전개도 베이스런 | 🐻 네모곰 | 직육면체 | 필드 베이스런 | 조건에 맞는 면이 놓인 **베이스**를 밟아 홈인 |
| 6 📊 평균 홈런 더비 | 🐼 고르미 | 평균과 가능성 | 필드 타격 | 평균·가능성을 구해 해당 **거리 존**으로 타구 |

각 종목은 60초 동안 진행되며 기록에 따라 동/은/금 메달이 주어집니다. 동메달 이상이면 그 종목의 ⭐별을 얻습니다.

## 📚 단원별 학습 단계 (자동 난이도 3단계)

| 종목 | ⭐ 1단계 | ⭐⭐ 2단계 | ⭐⭐⭐ 3단계 |
|---|---|---|---|
| 1 수의 범위와 어림하기 | 이상·이하·초과·미만 (경계값 함정 포함) | 올림·버림 (십·백의 자리) | 반올림 위주 (백의 자리) |
| 2 분수의 곱셈 | (진분수)×(자연수) | (자연수)×(대분수), (대분수)×(자연수) | (대분수)×(대분수), (진분수)×(진분수)×(자연수) |
| 3 합동과 대칭 | 세로 대칭축 | 가로·비스듬한 대칭축 | 점대칭 + **타구 2개 동시** |
| 4 소수의 곱셈 | (소수)×(자연수), 눈금 0.1 | (자연수)×(소수 두 자리), 눈금 0.1 | (소수)×(소수), **눈금 0.01** |
| 5 직육면체 | 십자형 전개도에서 마주 보는 면 | 겨냥도 보고 면·모서리·꼭짓점 수 세기 | **낯선 모양의 전개도**에서 마주 보는 면 / 만나지 않는 면 |
| 6 평균과 가능성 | 세 값의 평균 | 4~5개 값의 평균(소수 포함) | **평균이 주어질 때 빠진 값 역산** |

⭐ 종목 6은 매 라운드 **평균 문제와 가능성 문제가 번갈아** 나와 한 종목에서 단원 전체를 다룹니다.

오답 선택지는 아이들이 실제로 하는 실수를 흉내 내도록 만들었습니다 — 반올림 경계 실수, 소수점 자리 밀림, 평균을 최댓값·최솟값과 혼동 등.

바탕화면 경로에서는 로컬 서버가 권한 문제로 실행되지 않으므로, `/tmp`에 사본을 두고 서빙합니다.

```bash
rm -rf /tmp/mmo5 && mkdir -p /tmp/mmo5 && cp -R "/Users/mac/Desktop/클로드/motion-math-olympics-5th/." /tmp/mmo5/ && cd /tmp/mmo5 && python3 -m http.server 8795
```

브라우저에서 `http://localhost:8795` 접속. (카메라 권한이 필요한 모션인식 모드는 `localhost` 또는 HTTPS 환경에서만 정상 동작합니다.)

## 🎨 설계 노트

### 마리오파티에서 가져온 것들
- **보드 메타 구조**: 미니게임만 나열하지 않고, 주사위 → 칸 이동 → 이벤트(코인·보너스·한 번 더·랜덤 종목) → 종목 진입으로 이어지는 흐름을 만들었습니다. 종목 사이가 이어지면서 "한 판을 한다"는 감각이 생깁니다.
- **코인 → 별 환산**: 정답마다 코인이 튀어 올라 상단 카운터로 빨려 들어가고, 결과 화면에서 코인이 하나씩 세어지며 별로 바뀝니다.
- **룰카드**: 미니게임 직전에 규칙을 짧게 보여주는 화면. 모션 모드에서는 아이가 화면에서 떨어져 있을 수 있어 7초 뒤 자동으로 넘어갑니다.
- **판정 텍스트와 피버**: 반응 속도에 따라 `굿!` / `나이스!` / `퍼펙트!`가 뜨고, 콤보 5마다 8초간 코인 2배인 **피버 타임**이 옵니다.
- **관중석과 파티 장식**: 화면 위쪽에 작은 얼굴들이 앉아 흔들거리다가 정답에 만세를 부릅니다.

### 체육과 융합을 "테마"가 아니라 "조작"에 넣었습니다
- **종목 1**: 조준하고 웅크렸다 도약하는 동작이 그대로 멀리뛰기입니다. 착지 매트에는 **범위가 아니라 수 하나**만 적혀 있어서, 그 수가 조건 안에 드는지 스스로 판단해야 합니다. 범위를 적어두면 눈으로 짝만 맞추면 되기 때문입니다.
- **종목 2**: 좌우로 오가는 힘 게이지를 원하는 눈금에서 멈추는 것이 곧 "던지는 세기 조절"입니다. 게이지는 거리 눈금자와 **같은 x축**을 써서 "지금 던지면 저기 떨어진다"가 한눈에 보입니다.
- **종목 3**: 손을 움직이면 대칭축 반대편에 **거울 그림자 손**이 실시간으로 따라 움직입니다. 대칭 개념을 몸으로 느끼면서 조작할 수 있고, ⭐⭐⭐단계에서는 타구 2개가 동시에 날아와 **양손**을 써야 합니다(시리즈 최초).
- **종목 4**: 정답 수를 어디에도 글자로 알려주지 않습니다. 눈금만 그려두고 **직접 세어** 찾게 합니다. 단계가 오르면 눈금자의 척도가 0.1 → 0.01로 바뀌어 소수점 자리를 읽는 힘이 자랍니다.
- **종목 5**: 전개도를 접었을 때 어느 면이 어디로 가는지 **실제로 계산**합니다(종이 위를 굴러가는 주사위로 보고 각 칸의 3차원 방향을 추적). 덕분에 십자형뿐 아니라 계단형 같은 낯선 전개도도 정확히 채점합니다. 정답을 맞히면 **전개도가 접혀 직육면체가 되는 애니메이션**이 재생됩니다.
- **종목 6**: 정답을 맞히면 막대들이 **평균 높이로 스르륵 고르게 정리**됩니다. "평균 = 고르게 나눈 값"을 말이 아니라 움직임으로 보여줍니다.

### 아이가 억울하지 않도록
- 새 문제가 뜬 뒤 **0.8초 동안은 입력을 받지 않습니다.** 5학년은 계산이 길어져 3학년판(0.55초)보다 넉넉히 잡았습니다.
- 판정 범위에 여러 대상이 걸치면 **가장 가까운 것**을 고릅니다.
- **오답으로 점수가 깎이지 않습니다.** 콤보만 끊기고, 캐릭터가 "괜찮아!" 하며 아쉬워합니다.
- 종목 4·5·6은 스쳐 지나가도 처리되지 않도록 **잠깐 머물러야(홀드)** 확정됩니다.

### 5학년에 맞춘 조정
- 계산 시간이 길어지므로 메달 기준을 3학년판(4/7/10회)보다 낮춰 종목별로 3/5/8회 안팎으로 잡았습니다.
- 종목 2의 분수는 항상 **기약분수**로 제시됩니다.
- 종목 1의 오답은 반올림 경계값(649/650 등)처럼 실제로 헷갈리는 자리에만 놓아, 찍어서 맞히기 어렵게 했습니다.
